# Caesar Cipher
## Objective

> This is an ancient cryptography way of encrypting messages. Reason why I choice C language is cause it is a low level that teaches memory management either the programmer likes it or not.

### Dependencies

__Download C complier either `GCC` or `CLANG`.__

## Makefile

By default the Makefile uses `CLANG`.

Change the `${CC}` in the first line.

```
CC = gcc | clang
```

## Git Clone

```
$ git clone https://github.com/hakimyusuf48/CaesarCipher

$ cd CaesarCipher
```
### Execute

```
$ make

$ ./main

$ make clean
```
